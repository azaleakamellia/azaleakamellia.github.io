About

I'm a geospatial scientist currently doing my MPhil at UTM, where my research looks at correcting satellite rainfall data to better detect droughts in Sarawak — a part of the world where ground measurements are sparse and the stakes for getting it right are real. The work is done in collaboration with the Sarawak State Government.

By day I work as a geospatial consultant, which mostly means writing Python to wrangle satellite imagery into things that make sense to clients. I also built a drought indices library registered under MyIPO, which I'm quietly still improving.

Projects

Bias Correction of SPE Products for Drought Monitoring in Sarawak MPhil · Active

Evaluating and correcting CHIRPS, PERSIANN-CDR, and ERA5-Land over Sungai Sarawak basin using triple collocation error analysis and ML-based bias correction. In collaboration with the Sarawak State Government.

Drought Indices Calculation Library Registered · MyIPO

A software library for computing standardised drought indices from hydrometeorological inputs. Registered intellectual property under the Malaysia Intellectual Property Office.
