Below is a classified overview of my tools, intellectual property, and ongoing projects.

I. Featured Interactive Applications

Sarawak Tropical Land Cover Classifier Live Web App
Optical (S2) + SAR (S1) Fusion for Natural Capital Accounting
  • A cloud-based, interactive Google Earth Engine web app designed for rapid, high-confidence land cover classification in cloud-prone tropical environments.
  • Employs cutting-edge Optical and SAR data fusion to penetrate cloud cover and accurately distinguish natural forest from agriculture (e.g., oil palm) using Random Forest machine learning.
  • Directly applicable to ESIA baseline mapping, TNFD natural capital reporting, and ADB/IFC compliance verification.

OpenReceptor: Sensitive Receptor Detection Live Web App
Dynamic ESIA, TNFD, and ADB Baseline Mapping Tool
  • A browser-based, interactive geospatial tool that live-queries OpenStreetMap via the Overpass API to instantly extract sensitive human and environmental receptors.
  • Features dynamic Area of Influence (AoI) definition via drawing tools, file upload, or place search, allowing consultants to rapidly scope physical, biological, and socio-economic sensitivities.
  • Features one-click GeoJSON export for seamless integration into QGIS/ArcGIS workflows.

II. Registered Intellectual Property & Libraries

STEMRAINCAL Python Library MyIPO Registered
Independent Programmatic Library for Hydroclimatology
  • A robust Python library designed for computing standardised drought indices from hydrometeorological inputs.
  • Registered under the Malaysia Intellectual Property Office (MyIPO) to establish clear ownership while avoiding restrictive patents.
  • Currently under active development for an updated open-source release under the AGPLv3 license.
