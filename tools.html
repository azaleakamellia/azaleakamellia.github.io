  • Commercial Asset-Level Physical Climate & Drought Risk Profiling Pipeline
    An automated Python/Google Earth Engine workflow designed for corporate TCFD and ISSB (IFRS S2) reporting. The pipeline ingests client asset coordinates, retrieves ERA5-Land/CHIRPS/CMIP6 data, applies machine learning bias correction (XGBoost/Random Forest) against local station data, and outputs standardized SPI metrics and drought return periods.
    Tech Stack: Python (xarray, pandas, geopandas), Google Earth Engine, XGBoost, Random Forest.
    Acquire Commercial Enterprise License
  • Open Source Methodological Baselines & Field Manuals
    Open-access training materials, Jupyter Notebook exports, and baseline code for satellite precipitation calibration and SPI modeling. These resources are designed for students and researchers seeking to understand the fundamentals of hydroclimatic bias correction.
    License: CC BY-NC-SA 4.0
    View Open-Source Repository on GitHub
  • Open Source Standardized Precipitation Index (SPI) Calculator
    A Python library for computing SPI values from precipitation time series data. Includes gamma distribution fitting, probability calculation, and classification of drought/wet periods according to standard SPI categories.
    License: AGPLv3
    View Documentation
  • Open Source Google Earth Engine Preprocessing Scripts
    Collection of GEE JavaScript and Python scripts for downloading and preprocessing ERA5-Land, CHIRPS, and CMIP6 climate datasets. Includes temporal aggregation, spatial clipping, and format conversion utilities.
    License: MIT
